# Carve MCP server

MCP server for the Carve parser, linter, formatter, and renderers. This branch (`main`) runs the unreleased Carve 0.2 engine, pinned by commit from carve-js `main`. Carve 0.1 releases are maintained on the `0.1` branch. File access is enabled only for configured roots. Read the [Carve documentation](https://markup-carve.github.io/carve/) for the language syntax.

## Install

```sh
npm install -g @markup-carve/carve-mcp
```

## Usage

```sh
carve-mcp --help
```

# A short field guide

Good documentation helps a reader complete a task without first learning the
shape of the documentation system.

## Start with the outcome

Tell the reader what they will achieve. Then provide the few steps they need,
followed by technical detail only when it helps them decide or recover.

> Clear writing is not less precise. It puts precision where readers need it.
